# 실험 결과 요약

Gemma-4 다섯 크기(E2B · E4B · 12B · 26B-A4B · 31B)에 같은 데이터 · 같은 평가셋 · 같은 설정으로 LoRA 를 학습하고, 원본과 학습본을 비교했습니다 (6과제 × 5크기 = 30셀).

> 이 저장소에는 E2B · E4B 어댑터만 있습니다. 12B · 26B-A4B · 31B 는 결과만 참고용으로 싣습니다 (학습 후 성능이 E2B · E4B 와 같아 어댑터는 공개하지 않음).
> 평가 문항·모델 출력 예시는 학습 데이터 원문을 포함하므로 싣지 않았습니다.

---

## 1. 요약

- **모델을 키워도 학습 후 성능은 같습니다.** 6과제 모두 학습 후에는 E2B 와 31B 가 통계적으로 같은 높이에 멈춥니다. 성능을 막는 것은 모델 크기가 아니라 **데이터·라벨 설계** 입니다.
- **학습 효과가 있는 과제: 분류 3종(주제·상황·용어)과 요약.** 주제·용어 분류는 정확도 +12~30%p, 요약은 정답 형식·길이를 익혔습니다.
- **학습 효과가 없는 과제: 후속질문(오히려 열세) · 답변생성(동등).** 두 과제는 학습 데이터·과제 목표를 다시 정해야 합니다.
- **작은 모델(E2B · E4B) + LoRA 로 충분합니다.** 학습한 E2B 가 학습하지 않은 31B 보다 분류에서 크게 앞섭니다.

## 3. 과제별 결과 (학습 전 → 학습 후)

| 과제 | 지표 | E2B | E4B | 12B | 26B-A4B | 31B | 판정 |
|---|---|---|---|---|---|---|---|
| 주제분류 | 정확도 | 51.8 → **77.0%** | 58.6 → **77.8%** | 60.7 → **77.8%** | 62.0 → **77.6%** | 61.1 → **78.3%** | 학습 효과 큼 · 학습 후 크기 무관 |
| 상황분류 | macro F1 | 0.397 → **0.497** | 0.465 → **0.518** | 0.351 → **0.523** ※ | 0.328 → **0.508** | 0.378 → **0.526** | 효과 있으나 낮음 · E4B 에서 상한 |
| 용어추출 | macro F1 | 0.264 → **0.660** | 0.400 → **0.659** | 0.510 → **0.658** | 0.527 → **0.654** | 0.526 → **0.660** | 학습 효과 큼 · 학습 후 크기 무관 |
| 후속질문 | 학습본 승률 | 39.5% | 39.0% | 38.0% | 38.5% | 32.0% | **5개 모두 학습본 열세** (유의) |
| 답변생성 | 학습본 승률 | 51.5% | 44.5% | 56.0% | 45.5% | 53.5% | **5개 모두 차이 없음** |
| 요약 | 학습본 승률 | 100% | 99% | 96% | 90% | 94% | **5개 모두 학습본 우세** (유의) · 길이 효과 포함 |

※ 12B 상황분류는 학습률 1e-4 재학습 값 (§3-2).
분류의 학습 효과는 15셀 모두 통계적으로 유의합니다 (상황분류 E4B 만 폭이 작음: 정확도 +3.0%p).

### 3-1. 주제분류 — 학습 효과 큼, 상한 약 78%

- 원본은 클수록 낫지만 (51.8 → 62.0%), **학습 후에는 다섯 크기 모두 77~78% 로 같습니다.**
- **학습한 E2B (77.0%) 가 학습하지 않은 26B · 31B (약 62%) 보다 15%p 높습니다.**
- 남은 오류는 의미가 겹치는 라벨끼리의 혼동으로, 상한은 라벨 체계에서 옵니다.

### 3-2. 상황분류 — 효과 있으나 과제 자체의 상한이 낮음

- 학습 후 F1 0.50~0.53. E4B 이상은 서로 차이가 없습니다.
- 평가셋의 69% 가 '업무처리' 라 정확도 (약 70%) 는 "전부 업무처리" 수준입니다. 소수 클래스 '민원응대' 는 학습본도 13% 만 찾습니다.
- 원인: **질문 한 문장만으로는 상담 상황이 정해지지 않습니다** (답변·상담 전문이 있어야 판단 가능).
- 12B 는 학습률 2e-4 에서 학습이 불안정해 (손실 급등) F1 0.41 이었고, 학습률 1e-4 로 재학습하니 0.523 으로 다른 크기와 같아졌습니다. 이 셀만 학습률이 다릅니다.

### 3-3. 용어추출 — 학습 효과 큼, 상한 F1 0.66

- 학습 후 다섯 크기 모두 정확도 63~64%, F1 0.65~0.66 으로 사실상 같습니다.
- 남은 오류 (대출 · 대출연장 · 만기연장 등) 는 모든 모델에 공통입니다. **정답을 1개만 인정하는 라벨 체계** 가 상한을 만듭니다.

### 3-4. 후속질문 — 다섯 크기 모두 학습본이 열세

- 학습본 승률 32~40%, 모두 유의하게 원본보다 못합니다. 크기를 키워도 같습니다.
- 학습본은 데이터 정답처럼 짧은 되묻기 질문을 배웠는데, 그 상당수가 **답변에서 이미 안내한 내용을 다시 묻는** 질문입니다.
- 데이터의 '후속질문' 이 무엇을 위한 것인지 (고객이 이어 물을 질문 예측 / 상담원이 확인할 질문) 과제 목표부터 정해야 합니다.

### 3-5. 답변생성 — 다섯 크기 모두 동등

- 학습본 승률 44.5~56.0%, 모두 원본과 유의한 차이가 없습니다.
- 학습본은 정답처럼 짧고 상담원다운 답을 쓰지만, **조회 결과·금리·기간·서류를 단정하거나 지어냅니다.** 원본은 길고 대본·빈칸·조회 거절로 집니다. 서로 다른 이유로 지므로 무승부권입니다.
- 정답 데이터 자체가 실제 계좌 조회 결과를 전제로 한 답이 많아, 학습 데이터 정제 (조회 의존 답변 분리) 없이는 개선이 어렵습니다.

### 3-6. 요약 — 다섯 크기 모두 학습본 우세, 단 길이 효과 포함

- 학습본 승률 90~100%. 학습본은 정답과 거의 같은 길이 (약 160자) · 형식으로 씁니다.
- 원본은 정답의 2.9~6.2배 길이로 써서 루브릭의 길이 감점을 받았습니다. **원본 프롬프트에는 길이 지시가 없었습니다.** 따라서 승률의 상당 부분은 내용보다 길이·형식 차이입니다.
- 학습본이 가려진 값을 지어낸 사례가 드물게 있습니다 (31B 100건 중 1건).

## 5. 한계

1. 은행 분야만 학습했습니다 (보험·증권 분야는 하지 않음).
2. 단일 시드. 시드에 따른 흔들림은 12B 상황분류 1셀에서만 확인했습니다.
3. 원본은 라벨 목록만 받고 라벨 정의는 받지 않았습니다 (공식 정의 없음). 정의를 주면 원본 점수가 오를 수 있습니다.
4. 생성 과제는 LLM 1명이 고정 루브릭으로 블라인드 판정했습니다. 사람 검수는 하지 않았고, 평가셋이 과제당 100건이라 신뢰구간이 넓습니다.
5. 요약 승률에는 길이 효과가 섞여 있습니다 (§3-6).
